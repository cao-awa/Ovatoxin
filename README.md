# Ovatoxin
[English](README.md) | [中文](README_zh.md)

**Ovatoxin** is a modern Kotlin desktop UI framework, using DSL, rife with sugars.

# Getting started
Add codes to your ``build.gradle`` file:
```groovy
repositories {
    maven {
        url 'https://jitpack.io'
    }
}

dependencies {
    implementation 'com.github.cao-awa:Ovatoxin:{ovatoxin_version}'
}
```

For the versions, see [JitPack](https://jitpack.io/#cao-awa/Ovatoxin).
